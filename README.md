# AnyScope

AnyScope는 프로젝트별 코드를 다시 작성하지 않고,
문서 관리 화면에서 문서 유형과 하위 유형, 파일명 추천 키워드를 직접 구성할 수
있도록 기존 프로젝트와 분리했습니다.

## 현재 개발 범위

- PDF, Word, Excel 원본 업로드 및 검색 색인
- Windows.Media.Ocr 기반 Windows 네이티브 OCR 도우미와 브라우저 OCR 대안
- 사용자 정의 문서 유형과 2단계 상·하위 유형
- 파일명 키워드를 이용한 업로드 유형 자동 추천
- 저장된 유형에 따라 자동으로 바뀌는 검색 필터와 문서 수
- 기존 문서의 유형 이름을 읽는 하위 호환

## 로컬 실행

Node.js 22.13 이상과 pnpm이 필요합니다.

가장 쉬운 방법은 프로젝트 폴더의 `start-local.cmd`를 더블클릭하는 것입니다.
열린 명령 창을 닫지 않은 상태에서 아래 주소로 접속합니다.

<http://localhost:3000>

터미널에서 직접 실행하려면:

```bash
pnpm install
pnpm dev
```

개발 서버를 종료하려면 실행 중인 명령 창에서 `Ctrl+C`를 누릅니다.

로컬 검증:

```bash
pnpm lint
pnpm build
pnpm test
```

## 저장소 연결 원칙

`.openai/hosting.json`에는 기존 운영 사이트의 프로젝트 ID를 넣지 않습니다.
현재 파일의 `project_id`와 `d1`은 `null`이며, `DOCUMENTS`는 배포 시 별도로
연결해야 하는 R2 바인딩 이름일 뿐 기존 R2 버킷 연결이 아닙니다.

팀 비밀번호, API 키, 실제 R2 식별정보는 저장소에 커밋하지 말고 배포 환경의
비밀 변수로만 설정해야 합니다.

## 현재 상태

이 폴더는 로컬 개발 전용입니다. 운영 사이트 배포와 기존 R2 데이터 변경은
의도적으로 수행하지 않습니다.
