AnyScope Windows 네이티브 OCR 연결 도우미

최초 한 번만
1. 압축을 풉니다.
2. Install-AnyScope-OCR.cmd를 더블클릭합니다.
3. 설치 완료 메시지를 확인합니다.

이후 사용
1. AnyScope의 문서 관리 화면을 엽니다.
2. OCR이 필요한 문서의 'Windows OCR' 버튼을 클릭합니다.
3. 브라우저가 AnyScope Windows OCR 열기를 물으면 허용합니다.

사이트에서 선택한 문서와 짧은 유효기간의 전용 실행 권한이 도우미로 전달되므로,
문서 선택이나 팀 비밀번호 입력 없이 바로 처리됩니다.

필요 조건
- Windows 10 또는 Windows 11
- 인터넷 연결
- pdftoppm.exe가 포함된 Poppler

보안 및 데이터 처리
- 전용 실행 권한은 선택한 한 문서의 OCR에만 사용할 수 있습니다.
- 원본 PDF는 Windows 임시 폴더에만 내려받고 작업 종료 후 삭제합니다.
- OCR 결과만 AnyScope 검색 색인에 저장합니다.
- 운영 R2의 원본 문서를 삭제하거나 초기화하지 않습니다.
